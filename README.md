# Azure MCP

The official Azure MCP server. This plugin installs and configures it in your workspaces.

Upstream server docs: https://www.npmjs.com/package/@azure/mcp

Installs from the Camillia hub as `azure-mcp-d3498e`. On every new task the plugin posts
the ready-to-paste `mcp.servers` entry and the setup steps as a task comment.
